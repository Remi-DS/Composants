# Template — Page produit

> Statut : RECOMMANDATION de prototypage. Ce n'est pas un gabarit officiel Canopée.

## Objectif
Présenter une offre ou un produit, permettre sa compréhension puis proposer une action principale.

## Structure proposée
Header → Heading / introduction → présentation du produit → informations complémentaires → choix/comparaison si nécessaire → message contextuel si nécessaire → action principale → Footer.

## Composants candidats
Header, Heading, Content Item Mono, Content Item Duo, Card, Message, Message Bar, Tag, Button Primary, Button Secondary, Link, Footer.

## Règles IA
Cette structure est un squelette de prototype. Supprimer toute section non justifiée par le brief. Variantes, états, microcopies et règles de contenu doivent provenir des fiches composants ou du brief.

## Responsive
Appliquer `ai/responsive-grid.md` et les règles spécifiques des composants utilisés.
